# How to write a module summary (agreed with Shlomi, Nov 2026)

Before writing:
1. Read the chapter in the book itself (opening paragraph, learning objectives, interim summaries "סיכום ביניים").
2. Read the lecturer's topic list / questions for the chapter on Moodle (course page labels).
3. Build the summary around what the chapter is trying to teach and its link to the course's field
   (e.g. physiological psychology = how cells produce behavior), not a list of facts.
   Use the book's own central examples (e.g. withdrawal reflex + hot mug in Carlson ch2).
4. SOURCE RULE (standing): every fact, study, number and attribution must come from the ASSIGNED READING PAGES.
   No general knowledge or outside history. If a lecturer topic is not covered in those pages, write that
   explicitly ("הספר לא מפרט את זה בעמודי הקריאה – לבדוק בשקפים") instead of filling the gap.
   Everyday-life illustrations are fine only when clearly marked as an illustration, never as a finding.

Writing rules:
1. Audience: first-year student with zero background. Simple explanation beats brevity; length is fine.
2. Every concept: definition + the idea in plain words + an everyday-life example (book example in addition).
3. High/low, yes/no, internal/external criteria: explain as yes/no questions, with a full worked case for each outcome.
4. Section with several factors: the unifying idea first, then each factor as its own sub-section ("מה הרעיון" + example).
5. Every study: what they did / what came out / what it teaches.
6. Keep: opening (one-sentence question + how the parts connect), mini glossary, transition sentence opening each section,
   closing "השורה התחתונה: מה רוצים ממך" (story in 5 sentences + exam skills mapped to book objectives / lecturer questions),
   traps.
7. Self-contained: students will build further summaries from it.

Layout: no tables wider than 3 columns on phone; use <div class="ex"> cards instead. Wrap math like "r = −0.9" in <span dir="ltr">.
Check: python3 sumshot.py <page> and a full-page phone screenshot.
